# IPSP Lab 3: Circuits and Compact Models

This repository contains the material for Laboratory 3 of the Integrated Photonics Systems and Projects (IPSP) course. The notebook builds compact models for waveguides and couplers, connects them into Mach–Zehnder interferometers and ring resonators, and studies their wavelength-dependent responses.

## Requirements

- Git
- Python 3.12 (the required version is recorded in `.python-version`)
- [`uv`](https://docs.astral.sh/uv/getting-started/installation/), for creating the environment and installing the project dependencies
- Jupyter support, either through Visual Studio Code with the Jupyter extension or JupyterLab

No WSL setup is required. Use a terminal available on your operating system (PowerShell on Windows, Terminal on macOS, or a shell on Linux).

## Get started

Clone the repository and enter its directory:

```bash
git clone https://github.com/cccanvas-upv/ipsp-lab3.git
cd ipsp-lab3
```

Install the project dependencies from the lock file:

```bash
uv sync
```

`uv` creates a local `.venv` environment and installs the pinned dependency set from `uv.lock`. If Python 3.12 is not already installed, `uv` can install it when needed; otherwise, install Python 3.12 first and run `uv sync` again.

## Open the notebook

### Visual Studio Code

1. Open the cloned `ipsp-lab3` folder in Visual Studio Code.
2. Install the Microsoft **Jupyter** extension if it is not already installed.
3. Open `30_Circuits_&_CompactModels_STUDENT.ipynb`.
4. Select the project environment as the notebook kernel. It should appear as `.venv` or `Python 3.12`.
5. Run the cells from top to bottom.

### JupyterLab

From the repository directory, launch JupyterLab using the project environment:

```bash
uv run --with jupyterlab jupyter lab
```

Then open `30_Circuits_&_CompactModels_STUDENT.ipynb` in the browser tab that opens.

## Repository contents

- `30_Circuits_&_CompactModels_STUDENT.ipynb` — student notebook for the laboratory.
- `lab3_assets/` — figures used to explain the compact component models.
- `mzi.png`, `ring_s.png`, `ring_d.png` — circuit figures used in the notebook.
- `pyproject.toml` and `uv.lock` — project metadata and reproducible dependency definitions.

Run notebook cells in order. The plots are generated by the notebook as its simulation cells run.
